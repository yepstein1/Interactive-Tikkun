Custom Torah Font Setup

1) Put your licensed STaM/Torah font file in this folder.
2) Name it exactly: SeferSTaM.woff2
   (or use SeferSTaM.woff / SeferSTaM.ttf as fallback)
3) Refresh the app (Ctrl+F5).

Notes:
- The Torah panel is configured to prefer this local font first.
- If the custom file is missing, the app falls back to embedded Hebrew webfonts.
- Use only fonts you have rights to use.
